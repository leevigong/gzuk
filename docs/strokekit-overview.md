# strokekit 🎨

**한 줄 소개:** macOS 메뉴바 앱. 어느 화면이든 위에 그림 그릴 수 있어요.

## 어떻게 쓰나

1. 메뉴바 ✏️ 아이콘 클릭 또는 **⌘⇧⌥7** → 화면 위에 투명 캔버스 + floating toolbar 등장 (메뉴바는 그대로 보여요)
2. 도구 골라서 그림 그리기
3. 다시 ⌘⇧⌥7 또는 toolbar의 **✕** → 캔버스 사라짐 (그림은 메모리에 보존, 다시 켜면 그대로)

## 9가지 도구

- 🖌 **펜** — 자유롭게 그리기
- 🖍 **형광펜** — 반투명 두꺼운 선
- ╱ **직선** — 두 점 연결
- ↗ **화살표** — 화살표 그리기
- ▭ **사각형** — 빈 사각형 (드래그)
- ◯ **원** — 빈 원 (드래그)
- **Aa 텍스트** — 클릭 후 입력. **Shift+Enter** = 줄바꿈, **Enter** = 입력 완료. 화면 경계 도달 시 자동 줄바꿈. 한국어 IME 지원
- **① 카운터** — 클릭마다 1, 2, 3... 자동 증가. toolbar 아이콘이 다음 숫자를 미리 보여줌
- **🧽 지우개** — 클릭/드래그로 도형 단위 삭제

## 색상 & 굵기

- **8색 팔레트** (빨/주/노/초/파/보/흰/검). 흰색에도 미세한 윤곽선이 있어서 어디서나 보임
- **4단계 굵기** (2/4/6/10pt). 디폴트는 4pt

## 모드 토글

- 📝 **화이트보드 (square.and.pencil)** — 화면을 흰 배경으로 (어두운 화면에서 그림 잘 보이게). 메뉴바 영역은 가리지 않음
- 🖱 **통과 모드 (cursorarrow)** — 그림은 그대로 보이지만 클릭은 다른 앱으로 (터미널/브라우저 작업 가능). 같은 아이콘 + 배경 색깔로 토글 상태 표시

## 액션

- ↶ ↷ **Undo/Redo** (또는 ⌘Z / ⇧⌘Z)
- 🗑 **Clear** — 다 지우기
- ✕ **Close** — 그리기 모드 종료

## Floating Toolbar 디테일

- 메뉴바 ✏️ 아이콘 바로 아래가 디폴트 위치
- toolbar **빈 공간 어디든 드래그**로 이동 (하단의 ▬ 그립이 드래그 위치 힌트)
- 드래그 후 위치는 자동 저장, 다음에 켤 때 같은 자리

## 기타

- **다중 모니터** — 마우스가 있는 화면에 캔버스 뜸
- **메뉴바 앱** — Dock 안 차지함, 메뉴바 가리지 않음
- **첫 클릭 즉시 인식** — toolbar에서 도구 바꾸고 캔버스 클릭하면 바로 동작 (활성화 클릭 따로 안 필요)

## 차별점

- **DrawPen**: 도형 도구 없음 → strokekit은 9개 도구 다 있음
- **Annotate**: 도구가 메뉴 안 깊이 숨음 → strokekit은 floating toolbar로 항상 보임
- **Pensela**: 폐기됨 → strokekit은 새로 만든 오픈소스
- 통과 모드로 그림 위에서 다른 앱 작업 가능 (대부분의 경쟁 앱은 토글 시 그림이 사라짐)

## 한 줄 자랑

> "맥 메뉴바에서 ⌘⇧⌥7 누르면 화면 어디든 그림 그릴 수 있는 앱이야. Bandicam에서 그리기 기능만 떼어낸 느낌. 9개 도구 다 있고, 통과 모드로 그림 그대로 두고 다른 앱 만질 수 있어."
